App Library

@dile/lib is a package of components and mixins for building complete applications with minimal effort — covering feedback messages, user session state, and the routing system, so you don't wire up the same app-level plumbing every time.

What does @dile/lib offer?

This package provides a set of core features for applications, including:

Ready-made slices for managing basic application features:

  • UserSlice, for user management
  • FeedbackSlice, for feedback messages and loading states

Components that work directly with the Redux store:

  • Components for displaying feedback messages
  • Components for showing loading indicators

Components that help with routing system features:

  • A route guard that redirects unauthorized or unauthenticated users
  • Link components that trigger the routing system when clicked

Mixins that remove boilerplate from common app tasks:

  • Navigation using the routing system
  • Sending feedback messages and loading states
  • Syncing components with the Redux store
Unlike most Dile Components, which work independently of any stack beyond Web Components and Lit, @dile/lib requires Redux and Redux Toolkit and Lit Router to unlock its full potential. Starting a new app with these modules, components, and mixins is still much faster than building the equivalent from scratch — the benefits easily justify the extra dependencies.
