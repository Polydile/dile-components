# Backlog

Temas pendientes de abordar en el futuro, separados por carpetas según su naturaleza:

- `component-ideas/`: ideas de componentes nuevos.
- `accessibility/`: errores y mejoras de accesibilidad en componentes existentes.

Cada tema va en su propio archivo Markdown. Cuando se resuelve, se elimina el archivo en el mismo cambio que lo implementa.
