dile-list

The container and orchestrator component for lists, providing layout framing, property propagation, single/multiple selection, roving tabindex keyboard navigation, automatic last divider clipping, and empty/loading states.

1. Default Framed List with Auto-Dividers

Notice that child items do not define borders or radii; <dile-list> frames the list and automatically omits the divider on the last item.

2. Property Cascade: Compact & Clickable

3. Shared Icons

Set icon-prefix / icon-suffix on the list to show the same icon in every item. An item can use its own icon, or remove the list icon with an empty attribute (icon-suffix="").
