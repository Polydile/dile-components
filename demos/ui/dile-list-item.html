4. Line Clamping (lines="1", lines="2", lines="auto")

lines="1": This is a very long text that exceeds the available width of the container, so it is automatically truncated with an ellipsis on a single line thanks to the lines attribute. lines="2": This is an explanatory text with several sentences. When the content is longer than two lines, the component automatically applies line-clamp to truncate it neatly at the end of the second line without overflowing the container. lines="auto": The whole text is displayed without any limit on the number of lines, flowing vertically according to its natural length.

5. Alignment (Vertical align for Prefix/Suffix & Horizontal body-align)

align="start"

The prefix icon and the suffix elements are aligned to the top, while the body alignment is not affected.
align="center" (default)

The prefix icon and the suffix elements are vertically centered relative to the body block.
align="end"

The prefix icon and the suffix elements are aligned to the bottom of the row.

Horizontal alignment of the body with body-align or the CSS --dile-list-item-text-align custom property:

body-align="left" (default) body-align="center" body-align="right"
