dile-select-overlay component

Accessible alternative to dile-select that shows its options in a custom overlay panel instead of the native select dropdown.

Simple implementation

Icons

Options can show a leading icon from dile-iconlib, either per option (data-icon on the <option>) or as a default for the whole select (data-icon on the <select>, overridable per option).

Many options (max-height / scrolling)

The overlay grows with the option list up to --dile-select-overlay-max-height (260px by default) and then scrolls.

hideTrigger + composition API (preview of dile-select-ajax-overlay)

This is not a dile component below, just a plain <input>. It stands in for the search field that dile-select-ajax-overlay (next stage) will render itself. That component won't show dile-select-overlay's own trigger box (hideTrigger) — instead it opens the popup on focus and forwards its own keydown events to it via handleExternalKeydown(), so the hidden dile-select-overlay only contributes the options popup, positioned right under this field.

Focus the field, type, or use the arrow keys + Enter. highlightedText is shown below as you navigate.
