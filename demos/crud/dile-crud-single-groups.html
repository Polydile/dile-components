dile-crud-single component

Action groups in the sidebar layout

Actions listed in actions.singleGroups are rendered as blocks of full width buttons, with optional title, icon and variant (primary, outline or danger).

Left-aligned buttons in the sidebar layout

With --dile-crud-single-group-action-justify-content: flex-start (and --dile-crud-single-group-action-text-align: start for wrapped labels) every button in the actions column is aligned to the left.
