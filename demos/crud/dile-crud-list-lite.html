dile-crud-list-lite component

In this page you will find several demos:

  • Default rendering
  • maxItems + moreLinkLabel (progressive reveal)
  • footerLinkLabel + footerLinkUrl
  • Action buttons
  • Custom itemTemplate
  • disableLoadOnStart

Default rendering

Uses the default icon + label rendering. The API response has no ready-made URL field, so getResultList builds one from each country's slug, and linkProperty turns the label into a link to it.

maxItems + moreLinkLabel (progressive reveal)

Only 5 items are rendered at first (maxItems="5"), with a "Show more" link below. Each click reveals 5 more already-fetched items, until all of them are shown, at which point the link disappears.

footerLinkLabel + footerLinkUrl

A plain, always-visible footer link, e.g. pointing to a full listing page. Unlike moreLinkLabel, it doesn't depend on maxItems or reveal anything — it's just navigation.

Action buttons

Edit and delete buttons are shown. Clicking them logs crud-item-edit / crud-item-delete to the console.

Custom itemTemplate

Uses itemTemplate to render each item with the existing demo-country-item component.

disableLoadOnStart

With disableLoadOnStart, nothing is fetched until start() is called (here, via a button). Calling refresh() before that would also start it.
