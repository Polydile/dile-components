dile-qr-code component

A lightweight and reactive Web Component to render customizable QR codes on HTML5 Canvas using qr-creator, with support for embedded company logos.

Interactive Playground

Embedded Company Logos

The component automatically handles protective badge backgrounds, error correction level compensation (`H` level), and centered positioning.
